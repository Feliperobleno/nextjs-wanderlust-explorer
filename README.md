# nextjs-wanderlust-explorer
Wanderlust Explorer — React y Next.js

## Design References

Wanderlust Explorer se inspira en las siguientes plataformas de referencia para desarrollar una identidad visual propia:

### Airbnb Experiences
[https://www.airbnb.com/experiences](https://www.airbnb.com/experiences)

- Diseño limpio y protagonismo de la fotografía.
- Tarjetas de experiencias visualmente atractivas.
- Icono de corazón para gestionar favoritos.
- Referencia estética principal.

### GetYourGuide
[https://www.getyourguide.com/](https://www.getyourguide.com/)

- Organización de resultados de búsqueda.
- Distribución de filtros y controles de ordenamiento.
- Presentación de precios y valoraciones.
- Referencia funcional principal.

### Civitatis
[https://www.civitatis.com/es/](https://www.civitatis.com/es/)

- Organización de experiencias por destino.
- Jerarquía de información.
- Presentación de las páginas de detalle.
- Referencia complementaria de contenidos.

**Nota:** Wanderlust Explorer tendrá una identidad visual propia, utilizando estas plataformas como inspiración, sin reproducir literalmente sus diseños.
